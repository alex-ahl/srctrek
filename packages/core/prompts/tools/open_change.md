Open the change to build a tour of. `args` are the words a user would give `trail`: pull request URLs, repos (a folder or URL, optionally `@revision`), and ranges. A range applies to the repo just before it, or to the current repo when it comes first; a repo with no range after it is on the route without changes. No words: the current branch since it left its base branch. Returns every repo with its name, revision, and range; the other tools name a repo by that name.
