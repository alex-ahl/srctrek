# Contributing

srctrek is pre-release. Issues, ideas, and bug reports are welcome; there is no promise of
support or timelines, and the code changes without notice until version 1.

## Before a pull request

Open an issue first for anything beyond a small fix, so the change can be agreed before it's
built.

- Bun >= 1.3.14: `bun install`, then `bun run check` passes (typecheck, lint, format, tests,
  docs).
- One logical change per commit, with a Conventional Commits message.
- The project's rules are in [AGENTS.md](AGENTS.md); its design in [docs/](docs/README.md).
